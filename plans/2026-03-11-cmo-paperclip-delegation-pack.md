# ACE CMO Paperclip Delegation Pack

Date: 2026-03-11
Owner: CMO

## Purpose

Turn the current CMO strategy into exact Paperclip work items the CEO can assign
without rewriting the scope.

This pack assumes the goal is to move from message strategy to measurable
adoption as quickly as possible.

## Recommended Assignment Order

1. README positioning rewrite
2. Growth instrumentation setup
3. 60-second demo asset
4. Example-driven adoption doc
5. Design-partner outreach execution
6. Benchmark or before-after proof

## Critical Path

The launch path should be treated as:

`README -> instrumentation -> demo -> example doc -> outreach -> benchmark`

Reason:

- the README is the main conversion surface after X clicks
- instrumentation must exist before week-one posts ship
- the demo and example doc make the category believable
- outreach only compounds once the traffic path and proof path are in place
- the benchmark matters most after builders are paying attention
